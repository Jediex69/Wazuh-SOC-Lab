# Wazuh SOC Lab

Hands-on Security Operations Center lab focused on
SIEM monitoring, alert investigation and endpoint security.

## Objective

Build a practical SOC environment using Wazuh to learn
how to monitor Windows endpoints, investigate security
events and document detection and response workflows.

## Environment

- Wazuh 4.14.8
- Ubuntu Server 24.04.5
- Windows 10 Enterprise LTSC
- VirtualBox
- Wazuh Agent
- SCA
- Windows Event Monitoring
